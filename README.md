# 🌿 Guia de Saúde e Bem-Estar

Uma página web responsiva e elegante desenvolvida com foco em hábitos saudáveis, equilíbrio físico e mental, além de um formulário de contato integrado.

---

## 📌 Sobre o Projeto

O **Guia de Saúde e Bem-Estar** é uma landing page simples, intuitiva e informativa criada para compartilhar dicas práticas sobre autocuidado, nutrição, rotinas de exercícios e mindfulness.

O projeto inclui:
- **Navegação interna (links âncora):** Acesso rápido às seções principais da página.
- **Saúde Física:** Orientações sobre nutrição saudável e atividades físicas regulares.
- **Saúde Mental:** Recomendações sobre sono reparador e práticas de mindfulness.
- **Formulário de Contato:** Validação e captura interativa de mensagens via JavaScript.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias fundamentais da web (sem dependências externas):

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) **HTML5:** Estruturação semântica e acessível do conteúdo (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
- ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) **CSS3:** Estilização limpa, paleta moderna e harmoniosa, layout centrado e responsivo com Flexbox no formulário.
- ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) **JavaScript (Vanilla):** Manipulação do DOM para interceptar o envio do formulário, exibir feedback ao usuário e limpar os campos.

## 🚀 Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/saude-e-bem-estar.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd saude-e-bem-estar
   ```

3. **Abra o arquivo no navegador:**
   - Dê um duplo clique no arquivo `index.html`, ou:
   - Abra com a extensão **Live Server** no VS Code para recarregamento automático.
