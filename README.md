# app-bem-estar
# 🌿 Guia de Saúde e Bem-Estar

Uma página web responsiva e elegante desenvolvida com foco em hábitos saudáveis, equilíbrio físico e mental, além de um formulário de contato integrado.

---

## 📌 Sobre o Projeto

O **Guia de Saúde e Bem-Estar** é uma landing page simples, intuitiva e informativa criada para compartilhar dicas práticas sobre autocuidado, nutrição, rotinas de exercícios e mindfulness.

O projeto inclui:
- **Navegação interna (links âncora):** Acesso rápido às seções principais da página.
- **Saúde Física:** Orientações sobre nutrição saudável e atividades físicas regulares.
- **Saúde Mental:** Recomendações sobre sono reparador e práticas de mindfulness.
- **Formulário de Contato:** Validação e captura interativa de mensagens via JavaScript.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias fundamentais da web (sem frameworks ou dependências externas):

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) **HTML5:** Estruturação semântica e acessível (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
- ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) **CSS3:** Estilização limpa, paleta harmoniosa e layout centrado.
- ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) **JavaScript (Vanilla):** Manipulação do DOM para interceptar o envio do formulário, exibir confirmação e resetar os campos.
